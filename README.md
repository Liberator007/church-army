# Распорядок дня — презентация

Сайт-презентация по блокам из Notion (Армия → Программа):

- **4) Распорядок дня**: один слайд на каждый пункт с временем, заголовок и изображение.
- **6) Скользкие моменты**: слайд со списком тем, затем по слайду на каждую тему,
  у дедовщины ещё по слайду на каждый подпункт. Эти слайды без изображений.

## Запуск

Откройте `index.html` в браузере (двойной клик или через GitHub Pages).

Управление:

- **→ / пробел / Enter / клик по правому краю**: следующий слайд
- **← / клик по левому краю**: предыдущий слайд
- **F**: полноэкранный режим
- свайп влево/вправо на телефоне

## Изображения

Положите картинки в папку `images/` с номером слайда в имени
(подходят `.jpg`, `.jpeg`, `.png`, `.webp`). Пока картинки нет, на слайде видна заглушка.

| Файл | Слайд |
|------|-------|
| `images/01.jpg` | 6:00 — подъём |
| `images/02.jpg` | 6:10 — зарядка / уборка территории |
| `images/03.jpg` | 6:50 — утренний осмотр |
| `images/04.jpg` | 7:10 — построение на завтрак, завтрак |
| `images/05.jpg` | 8:30 — развод |
| `images/06.jpg` | 12:50 — контрольное построение, обед |
| `images/07.jpg` | 14:30 — второй развод |
| `images/08.jpg` | 17:50 — контрольное построение |
| `images/09.jpg` | 18:30 — ужин |
| `images/10.jpg` | 19:00 / 19:30 — свободное время |
| `images/11.jpg` | 21:00 — «Панорама» |
| `images/12.jpg` | 21:20 — прогулка |
| `images/13.jpg` | 21:40 — вечерняя поверка |
| `images/14.jpg` | 22:00 — отбой |

Список пунктов и пути к картинкам задаются в массиве `SLIDES` в `index.html`.
